## Task 02: Automated Web Scraping

The Task 02 project uses the Books to Scrape practice website to collect book information across 50 catalogue pages.

### Extracted Data

- Book title
- Price (GBP)
- Numeric star rating
- Availability status
- Product URL

The notebook execution output records 1,000 extracted books.

### Tools & Technologies

- Python
- Requests
- BeautifulSoup
- lxml
- Pandas
- Google Colab
- GitHub

### Task 02 Files

- `PROGREE_Task_02_Web_Scraping.ipynb` — scraping pipeline and execution output.
- `extracted_books.csv` — extracted dataset.
- `PROGREE_Task_02_Report.docx` — project report.
